# Homebrew Bohor

Official Homebrew tap for Bohor tools.

## Installation

```bash
brew tap gUBII/bohor
brew install bohor-runner
```

## Usage

```bash
# First-time pairing wizard
bohor-runner setup --api-url https://bohor.com.au

# Interactive TUI dashboard
bohor-runner --api-url https://bohor.com.au
```
